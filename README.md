welcome,
this was simply inspired by the exact reason i decided to start learning how to code and discovered athena in the first place - i was fed up with myself for only ever planning, creating a never ending list of things to do, but never actually doing anything about anything.
so i decided, let's just take the first step - even if its not perfect, not amazing, but just drives the momentum, its okay.
its a simple web page with html and css that has some copy pasted content from my own journal entry (except for all the cuss words) - totally minimal, because i didnt wanna overthink and give up   

The project has:
  - a list of my interests (aka things i only think about, not really execute, not anymore tho :)
  - a sticky note with things i want my future self to follow and live by
  - a little informal intro
in short, thanks to this hackathons and the extrinsic motivation of all the cool artifacts - i finally build smth even when it was hard (feels great).

What I struggled with
- Github and deploying the pages correctly, syncing VS code and github - all the technical part was difficult for sure, but I figured it out in the end
- The CSS took the most time, had to keep switching sites to make the website look like the way it looked in my head. But prior knowledge from school about html and css helped for sure. A lot of trial and error was involved

What I learnt
- I spent time before watching tutorial videos and copying code from there, but realised buildng a project all by yourself is very different, and thats the way you actually learn things, not just theory. From now on every time I learn something new, I'm going to ensure I'm applying the knowledge in a project immediately.
- Perfectionism slows down things a lot, if a section is 80% done, I need to move on and move to the next part, i can polish later.
- Don't give up on technical hurdles - they're annoying and really make you want to give up, but having solved it in the end feels awesome.

thanks for reading :)
